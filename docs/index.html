Генератор темы VelumVPN

Соберите палитру и скопируйте строку в заголовок ответа color-profile. Приложение переключит тему у тех, у кого эта подписка сейчас открыта. Готовые имена и остальные заголовки описаны в wiki.

Имя заголовка — color-profile, значение — девять цветов через дефис: фон, шапка, карточка, плитка, граница, основной, акцент, текст, приглушённый. «Подключено» берёт акцентный цвет. Зелёный и оранжевый статусы приложение оставляет своими.

Готовые темы одной строкой

Если своя палитра не нужна, в тот же заголовок кладётся имя: original, blue, red, orange, green, purple, pink. resetcolors возвращает оригинальную тему.
